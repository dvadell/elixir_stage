A sweep of weak assertions that pass for the wrong reason, plus missing
boundary/negative coverage. Grouped per file; each item says what to assert
instead. (WAV/wav_test items live in T0022; speech_text behavior+tests in
T0024; TTS runtime coupling in T0037.)

## Scope

### Controllers

- `transcription_controller_test.exs`
  - Body-param precedence (~81): also assert the supplied id was actually
    used as context (e.g. its stored messages fed to the fake LLM), not just
    that ids differ.
  - Reset test (~100): assert prior turn's `:user` message is absent from the
    fresh context, not merely that no `:user` role exists.
  - Error-mapping tests (~156): stop substring-matching provider message
    text ("Timed out waiting..."); map via structured reasons/atoms so 502 vs
    504 coverage survives wording refactors.
- `home_controller_test.exs`: replace raw-substring checks
  (`html =~ "id=\"model-loading\""`) with structural queries (Floki/LazyHTML
  on stable ids/roles) — two flagged spots.
- `settings_controller_test.exs:47-49`: parse the `<select>` node and assert
  ordered option values instead of splitting the whole document on raw value
  strings.
- `error_json_test.exs`: cover more statuses the app renders (401/403/422)
  plus the catch-all fallback once T0025 lands it.

### Components/layouts

- `core_components_test.exs`: assert class/attr placement structurally
  (`hero-x-mark` on the icon element; `disabled="disabled"` on the button)
  rather than `html =~ "..."`; add unchecked-checkbox and empty-options
  select cases.
- `layouts_test.exs:12-16`: add negative flash cases — wrong-kind message
  must not render, empty flash renders no alert content.

### Conversation

- `conversation_test.exs:118`: drain the first turn's captured message before
  binding (`assert_received` matches the oldest); compare the intended
  turn-2 system prompt explicitly (mailbox count/receive pattern).
- `weather_test.exs`: add coordinate-only forecast failure test (5xx /
  transport error) locking the error contract; extract shared
  `@expected_params` helper + sync comment instead of repeating serialized
  param maps (~339).

## Tests

Each bullet above *is* the test change. Sanity check the suite catches
regressions: temporarily mutate one production line per area (e.g. remove
clamping, skip reset delete) and confirm exactly the strengthened assertions
fail.
