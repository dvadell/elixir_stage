----
title: Add a / page
----
Add a / page. The page should have only one button with a microphone icon/emoji. The button must fill the whole screen. This will be a full page application with only one huge button.

There are only two possible actions for the button:
* The button is pressed and the user keeps the pressure.
* The button is released.

When the button is pressed, and while the user has the button pressed:
* The browser should start recording

When the button is released: 
* the recording should stop.
* A browser-native speech-to-text API should be called to turn the speech into text.
* The text should be logged to the browser's console using `console.log()`.

The interface is voice-first, so the only visible HTML object is a button.
