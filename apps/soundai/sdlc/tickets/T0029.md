----
title: Whisper worker — WebGPU→WASM fallback race & language default
----

Two issues in `assets/js/whisper_worker.js`, one of them a real race that can
fail the first utterance after a WebGPU init failure.

## Scope

### 1. Fallback race (high — lines 71-80)

When WebGPU initialization fails, the rejected promise stays assigned to
`pipelinePromise` while the WASM fallback loads. A `transcribe` message
arriving in that window awaits the stale rejected promise → spurious failure
even though WASM would succeed.

Fix: clear/null the failed reference before starting the fallback (track the
in-flight load promise separately from the resolved pipeline), and make
`transcribe` await whichever load attempt is current (or queue messages until
the pipeline is ready). Ensure no path can leave a rejected promise stored as
the "ready" pipeline.

### 2. Hardcoded default language (low — line 99)

`language: language || "spanish"` bakes a business rule into code and
prevents auto-detect. Hoist it to a named constant (`DEFAULT_LANGUAGE`) at
the top of the file with a comment, or omit `language` when not provided so
the model auto-detects. Given the product is Spanish-first (PRD), keeping a
configurable default is acceptable — decide and document; do not silently
leave the magic string inline.

## Tests

The STT flow is browser-verified per TECH_DESCRIPTION §10 (no JS unit harness
for the worker), so this ticket ships with a manual test matrix:

- Force WebGPU off (browser flag / unsupported browser) → first utterance
  transcribes via WASM with no console error.
- Speak immediately after page load while the model is still loading →
  utterance either waits or fails cleanly once, and the *next* utterance
  works (no permanently wedged state).
- Repeat the WebGPU-failure scenario several times to exercise the race
  window; confirm zero spurious failures.
- `?model=&language=` overrides still work end-to-end.

## Acceptance criteria

- [ ] No rejected-promise window: a transcribe request during fallback never
      consumes the stale rejection.
- [ ] Language default is a documented, single point of configuration.
- [ ] Manual matrix above executed on Chrome (WebGPU) and Firefox (WASM).
