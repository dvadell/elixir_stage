----
title: Client bootstrap & settings hardening (cookie crash, init dedupe, SW failure surfacing)
----

Small robustness fixes across `settings.js`, `app.js`, and `tts_config.js`
that currently abort page mount or silently degrade.

## Scope

### 1. Malformed cookie crashes settings mount (`assets/js/settings.js:19`)

`decodeURIComponent` throws `URIError` on malformed percent-encoding
(`%zz`, truncated `%`) — cookies are user-editable, so a single bad cookie
aborts the whole settings module at mount. Wrap in try/catch returning null
(treat as unset).

### 2. Cookie Secure flag (`settings.js:26`)

Append `; Secure` when `location.protocol === "https:"` (keep plain-http dev
working).

### 3. Listener cleanup (low, optional — `settings.js:68-72`)

Return an unbind function from `mountSelect` so future re-mounts/unmounts
don't leak listeners; keep the existing `mountedKey` guard behavior.

### 4. Deduplicate boot path (`assets/js/app.js:56-67`)

The `readyState === "loading"` / else branches duplicate the boot+init call
list; extract one `init()` called from both so they can't drift.

### 5. Surface service-worker failure (low — `app.js:49-51`)

SW registration failure is only `console.warn`'d — offline-first silently
degrades. Reuse the existing offline banner to note that offline mode is
unavailable (keep the warn for logs).

### 6. Empty-models guard (`assets/js/tts_config.js:36-38`)

`getModelConfig` falls back to `this.models[0]`, which is `undefined` if the
array is empty → callers throw on `.dtype`. Guard and return undefined
explicitly (documented), letting callers take their error path.

## Tests

Manual matrix (no JS unit harness for these modules):

- Set a corrupt cookie (`document.cookie = "soundai_tts=%zz"`) → `/settings`
  loads with defaults selected; no console exception.
- Settings change persists over HTTPS deployment (Secure attr visible in
  devtools) and still works on http://localhost.
- Block SW registration (devtools "Bypass for network"/unregister + fail) →
  banner notes degraded offline mode once, app still functional.
- `npm run build`/`mix assets.build` green after refactor; voice flow smoke:
  press → speak → reply still works after init() dedupe.
