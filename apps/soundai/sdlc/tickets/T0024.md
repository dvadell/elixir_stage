----
title: SpeechText correctness — thousands separators, over-broad emoji stripping, non-string fallback
----

`Soundai.Conversation.SpeechText.clean/1` mangles legitimate LLM content on
its way to TTS. Three fixes, ordered by severity.

## Scope

### 1. Decimal comma vs thousands separator (high — `speech_text.ex:44,68`)

`~r/(\d),(\d)/` turns "1,234" into "1 coma 234" — any large number formatted
with thousands separators is mispronounced. Fix:

- First remove commas used as thousand separators (groups of exactly three
  digits at word/end boundaries, e.g. ~r/(\d),(?=\d{3}(?!\d))/ → "\\1"),
- then apply the decimal-comma replacement ("12,6" → "12 coma 6").
- Note the LLM may emit either locale convention ("1.234,56" es vs
  "1,234.56" en). Handle both without breaking "12,6"; pin the exact rules in
  the moduledoc.

### 2. Narrow the symbol-stripping ranges (medium — `speech_text.ex:35`)

`\x{1F000}-\x{1FAFF}` plus `2190–21FF`, `2300–23FF`, `2460–24FF`,
`25A0–27BF`, `2B00–2BFF` includes unassigned code points and meaningful
symbols (arrows in answers, circled numbers ①②③). Narrow to actually-assigned
emoji blocks + variation selectors (`FE00–FE0F`) + ZWJ (`200D`). For
borderline useful characters (arrows, circled digits) prefer translating to
words ("→" → "va a", "①" → "(1)") over deletion — decide per block and record
the mapping table in the moduledoc.

### 3. Non-binary fallback (`speech_text.ex:73`)

`def clean(other), do: other` silently forwards `nil`/atoms/lists downstream
to TTS. Change to log a warning and return `""` (voice-safe), narrowing the
spec to `binary() -> binary()`.

### 4. Pin the gaps the tests miss today

Add tests that would have caught regressions here:

- Unbalanced emphasis survives cleaning wrongly today: "**Hola" and
  "se corta*" must not reach TTS with asterisks (extend the emphasis regex
  handling to strip lone marker runs).
- Nested emphasis ("**negrita *con* anidada**") currently uncleaned — fix or
  explicitly document as accepted.
- Case variants: "KM/H", "Kmh", "30°c", "30°C" (no space).
- Stray "%" not attached to a number ("el % de votos") — pin intended output.

## Tests

- Unit tests for each rule above with exact expected strings (this module is
  pure — exhaustive tables are cheap).
- Property-ish sanity: cleaned output never contains `*`, `` ` ``, `#`, `%`,
  `°`.

## Acceptance criteria

- [ ] "1,234"/"1.234" pronounced correctly; "12,6" still "doce coma seis".
- [ ] Assigned emoji stripped; meaningful symbols translated or kept per the
      documented table; no silent data loss beyond the table.
- [ ] Non-binary input cannot leak to TTS.
- [ ] Emphasis edge cases covered and handled.
